# DigiChakra360 - Free Trial Landing Page

A modern, responsive landing page for DigiChakra360, a digital marketing service offering data-driven strategies to supercharge brand presence. Built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Hero Section**: Eye-catching gradient background with animated elements and clear call-to-action
- **Features Overview**: Highlights the 3-day free trial benefits including:
  - Digital Audit & Strategy Blueprint
  - Ad Campaign Mockups & Performance Insights
  - Personalized Growth Consultation
  - Access to premium tools (SEO Tools, Analytics Dashboard, Content Planner, A/B Testing)
- **Signup Form**: Secure, no-credit-card-required registration with business type selection
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Gradient backgrounds, smooth animations, and professional styling
- **Performance Optimized**: Built with Vite for fast development and production builds

## 🛠 Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with PostCSS and Autoprefixer
- **Icons**: Lucide React
- **Backend Integration**: Supabase (for future authentication and data handling)
- **Linting**: ESLint with TypeScript support
- **Development**: Hot module replacement, TypeScript checking

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd digichakra
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` (or the port shown in terminal)

## 🚀 Usage

The landing page is designed to convert visitors into trial signups. Key user flows:

1. **Hero Section**: Visitors land on the page and are immediately presented with the value proposition
2. **Features Section**: Learn about what's included in the free trial
3. **Signup Section**: Fill out the form with name, email, and business type
4. **Success State**: Confirmation message after form submission

## 📜 Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality checks
- `npm run typecheck` - Run TypeScript type checking

## 🎨 Customization

### Styling
- Colors and gradients can be modified in the component files
- Tailwind configuration in `tailwind.config.js`
- Custom CSS in `src/index.css`

### Content
- Update text, features, and benefits in respective component files
- Modify form fields and validation in `SignupSection.tsx`
- Update footer links and company information in `Footer.tsx`

### Supabase Integration
The project includes Supabase setup for future backend integration:
- Authentication for user management
- Database for storing trial signups
- Real-time updates and analytics

## 📱 Responsive Design

The page is fully responsive with breakpoints for:
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
